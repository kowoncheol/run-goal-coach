# Run Goal Coach

목표 대회 기록에 맞는 주간 훈련 계획과 수행 결과 피드백을 제공하는 Android 앱이다.

현재 단계는 프로젝트 계획 수립이며, 실행 가능한 앱은 아직 포함하지 않는다.

## 1. 프로젝트 목표

사용자가 대회 날짜와 목표 기록, 현재 실력을 입력하면 온디바이스 AI가 일주일 훈련 계획을 제안한다. 사용자는 훈련 결과를 간단히 입력하고, 한 주가 끝나면 계획 대비 수행 결과에 대한 피드백을 확인한다.

첫 버전은 10km 대회만 지원한다. 외부 AI API와 중간 서버를 사용하지 않고, 모델 준비 후 계획 생성과 데이터 저장을 휴대폰 안에서 처리하는 것을 목표로 한다.

## 2. 기본 기능

| 기능 | 내용 |
| --- | --- |
| 목표 설정 | 대회 날짜, 목표 기록, 현재 러닝 기록, 평소 주간 거리, 훈련 가능 요일 입력 |
| 주간 계획 생성 | 목표까지 남은 기간과 현재 수준을 반영해 일주일의 훈련과 휴식 제안 |
| 결과 입력 | 완료 여부, 실제 거리와 시간, 체감 난이도 입력 |
| 주간 피드백 | 계획과 결과를 비교하고 수행 정도와 다음 주 참고 사항 설명 |

결과 입력에서 미입력과 미완료를 구분한다. 미완료 시 시간 부족 또는 훈련 부담 등의 이유를 간단히 선택할 수 있게 한다.

## 3. 이용 흐름

1. 목표와 현재 상태를 입력한다.
2. 주간 계획 생성 버튼을 누른다.
3. 요일별 훈련 내용과 추천 이유를 확인하고 계획을 저장한다.
4. 훈련을 마친 뒤 간단한 수행 결과를 입력한다.
5. 주간 피드백 버튼으로 결과 분석을 확인한다.
6. 다음 주 계획 생성 시 지난주 요약과 피드백을 참고한다.

주간 피드백은 사용자가 앱에서 요청할 때 생성한다. 백그라운드 자동 생성이나 알림 예약 기능은 첫 버전에 넣지 않는다.

## 4. 온디바이스 AI 적용 방식

AI는 미리 정의한 훈련 후보 안에서 주간 구성을 추천하고, 기록을 바탕으로 피드백을 설명한다. 앱 코드는 날짜·거리·페이스·완료율 계산과 결과 검증을 담당한다.

- 훈련 유형은 가벼운 달리기, 지속주, 인터벌, 긴 거리 달리기, 휴식 등으로 제한한다.
- 훈련별 수치 범위와 주간 조정 기준은 근거를 확인한 후 별도로 확정한다.
- 목표 기록만으로 강도를 정하지 않고 현재 기록과 평소 훈련량도 반영한다.
- AI 응답은 날짜, 훈련 후보 ID, 거리 또는 시간, 강도, 설명을 포함한 정해진 형식으로 받는다.
- 앱은 가능 요일, 누락·중복 날짜, 허용되지 않은 후보, 수치 및 단위 오류를 검사한다.
- 검증 실패 시 잘못된 계획을 저장하지 않고 다시 요청하도록 안내한다.
- 생성 중에는 진행 상태를 표시하고 중복 요청을 막는다.

실제 모델과 실행 라이브러리는 테스트 휴대폰의 호환성, 한국어 출력, 생성 속도와 메모리 사용을 확인한 뒤 선정한다. 모델 초기 배치 방식과 라이선스도 함께 확인한다. 훈련 계획의 적절성은 문장 생성 여부와 별도로 검증한다.

## 5. 화면 구성

| 화면 | 표시 및 입력 내용 |
| --- | --- |
| 목표 설정 | 대회 날짜, 목표 기록, 현재 상태, 가능한 요일 |
| 이번 주 계획 | 요일별 훈련, 훈련 목적, 계획 생성·저장 |
| 훈련 결과 입력 | 완료 여부, 거리, 시간, 체감 난이도 |
| 주간 피드백 | 주간 수행 요약, AI 피드백, 다음 주 참고 사항 |

## 6. 개발 환경과 저장

- 개발 도구: Android Studio
- 화면: Java와 XML
- 저장: Room DB
- AI 처리: 기기 내 모델 실행
- 필요 시 AI 연결부에만 Kotlin 사용
- 모델·라이브러리 버전과 최소 Android 버전은 실기기 검증 후 결정

| 데이터 | 주요 항목 |
| --- | --- |
| 목표 | 대회 날짜, 목표 기록, 현재 기록, 평소 주간 거리, 가능 요일 |
| 주간 계획 | 해당 주, 요일별 훈련, 목표 거리·시간·강도 |
| 수행 기록 | 계획 ID, 완료 여부, 실제 거리·시간, 난이도, 미완료 이유 |
| 주간 피드백 | 해당 주, 수행 요약, 피드백 내용 |

앱을 종료해도 저장한 목표와 계획, 수행 기록, 피드백을 다시 확인할 수 있게 한다. 개인 기록과 모델 파일은 GitHub에 올리지 않는다.

## 7. 개발 순서

1. **AI 실행 확인:** 실제 휴대폰에서 짧은 한국어 응답을 생성하고 오프라인 동작·속도·메모리를 확인한다.
2. **기본 화면과 저장:** 목표 설정, 주간 계획 표시, 결과 입력과 Room 저장을 연결한다.
3. **주간 계획 생성:** 훈련 후보와 검증 기준을 정하고 AI 추천 결과를 일정표로 표시한다.
4. **주간 피드백:** 코드로 계산한 수행 요약을 AI에 전달해 설명을 생성한다.
5. **전체 흐름 확인:** 목표 입력부터 계획 생성, 결과 저장, 피드백까지 시연한다.

## 8. 완료 기준

- 사용자 목표와 가능 요일에 맞는 일주일 계획을 표시한다.
- 결과 입력 후 계획과 실제 수행을 비교한 주간 피드백을 제공한다.
- 누락된 입력과 잘못된 AI 출력은 저장 전에 검사한다.
- 미입력 기록을 훈련 실패로 단정하지 않는다.
- 앱 재실행 후 기존 기록을 복원한다.
- 모델 준비 후 네트워크 없이 핵심 흐름이 동작한다.
- 모델 로딩이나 생성 실패 시 오류 안내 후 재시도가 가능하다.

## 9. 제외할 기능

지도, 코스 추천, GPS 자동 측정, 워치 연동, 회원가입, 클라우드 동기화, 소셜 기능, 실시간 코칭과 복잡한 통계는 첫 버전에서 제외한다.

## 10. 다음 확인 사항

우선 테스트할 Android 휴대폰 모델을 정하고 온디바이스 모델의 실행 가능성을 확인한다. 초기 개발 범위는 주간 계획과 피드백으로 유지하며, 추가 기능은 기본 흐름을 완성한 후 검토한다.
