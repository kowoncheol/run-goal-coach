# Run Goal Coach

목표 대회 기록에 맞는 주간 훈련 계획과 수행 결과 피드백을 제공하는 Android 앱이다.

현재는 프로젝트 계획 단계이며, 실행 가능한 앱 코드는 아직 포함하지 않는다.

## 1. 프로젝트 목표

대회 날짜와 목표 기록, 현재 실력과 훈련 가능 요일을 입력하면 일주일 훈련 계획을 제안한다. 훈련 후 간단한 수행 결과를 기록하고, 한 주가 끝나면 계획 대비 수행 결과와 다음 주 참고 사항을 확인한다.

첫 버전은 10km 대회를 대상으로 하며, 복잡한 연동 없이 휴대폰에서 단독으로 사용할 수 있는 기본 기능에 집중한다.

## 2. 기본 기능

| 기능 | 입력 또는 처리 내용 |
| --- | --- |
| 목표 설정 | 대회 날짜, 목표 기록, 현재 러닝 기록, 평소 주간 거리, 훈련 가능 요일 |
| 주간 계획 생성 | 목표까지 남은 기간과 현재 수준에 맞춰 요일별 훈련·휴식 구성 |
| 결과 입력 | 완료 여부, 실제 거리·시간, 체감 난이도와 간단한 미완료 이유 |
| 주간 피드백 | 완료율, 계획 대비 실제 거리·시간, 체감 난이도 비교와 다음 주 참고 사항 |

기록을 입력하지 않은 상태와 실제로 훈련을 완료하지 못한 상태를 구분한다.

## 3. 이용 흐름

1. 목표와 현재 상태를 입력한다.
2. 주간 계획 생성 버튼을 눌러 이번 주 훈련 내용을 확인하고 저장한다.
3. 훈련을 마친 뒤 실제 거리·시간과 체감 난이도를 입력한다.
4. 주간 피드백 버튼으로 수행 요약과 다음 주 참고 사항을 확인한다.
5. 다음 주 계획을 생성할 때 지난주 결과를 반영한다.

계획과 피드백은 사용자가 앱에서 요청할 때 제공한다. 백그라운드 자동 생성과 알림 예약은 첫 버전에 넣지 않는다.

## 4. 주간 계획과 피드백 구성

초기 버전은 미리 정한 훈련 유형과 구성 규칙을 사용한다. 목표 기록뿐 아니라 현재 기록, 평소 주간 거리, 가능한 요일을 함께 반영한다.

- 가벼운 달리기, 지속주, 인터벌, 긴 거리 달리기와 휴식 등 훈련 유형을 정의한다.
- 남은 기간과 현재 수준에 맞는 훈련 후보를 선택하여 가능한 요일에 배치한다.
- 훈련 유형별 거리·시간·강도 범위와 주간 조정 기준은 근거를 확인한 뒤 확정한다.
- 앱에서 날짜·페이스·완료율과 주간 합계를 계산하고, 입력 누락·날짜 중복·잘못된 수치를 검사한다.
- 피드백은 실제 수행 요약과 체감 난이도, 미완료 이유에 따라 미리 정한 설명을 조합한다.
- 다음 주 계획에는 완료 여부만이 아니라 훈련 부담과 일정상의 이유를 구분해 반영한다.

추천·조정 기준과 사용자 화면은 기본 기능을 구현하면서 검증한다. 목표 달성을 보장하는 방식으로 표현하지 않는다.

## 5. 화면 구성

| 화면 | 주요 내용 |
| --- | --- |
| 목표 설정 | 대회 날짜, 목표 기록, 현재 상태, 가능한 요일 입력 |
| 이번 주 계획 | 요일별 훈련, 거리 또는 시간, 훈련 목적과 저장 |
| 훈련 결과 입력 | 완료 여부, 실제 거리·시간, 체감 난이도 |
| 주간 피드백 | 수행 요약, 피드백과 다음 주 참고 사항 |

## 6. 사용 예시

다음 내용은 화면과 동작을 설명하기 위한 가상 예시다. 실제 훈련 처방이나 구현 완료 결과가 아니다.

- 목표: 2027년 3월 21일 10km 50분 미만
- 현재 상태: 최근 10km 기록 60분, 평소 주간 거리 15km
- 가능 요일: 화요일, 목요일, 일요일
- 주간 계획 화면: 가능한 요일에 훈련을 배치하고 나머지 요일은 휴식으로 표시
- 수행 결과 예시: 계획한 3회 중 2회 완료, 집중 훈련은 어렵게 기록, 1회는 시간 부족으로 미완료
- 피드백 예시: 완료율 67%와 미완료 이유를 보여주고, 훈련 강도 유지와 다음 주 가능 요일 확인을 제안

거리와 강도 등 구체적인 훈련 수치는 검증한 구성 기준에 따라 결정한다.

## 7. 개발 환경과 데이터 저장

- 개발 도구: Android Studio
- 화면: Java와 XML
- 데이터 저장: Room DB
- 계획 생성과 피드백: 앱 내부의 훈련 구성 규칙과 결과 비교 로직

| 데이터 | 주요 항목 |
| --- | --- |
| 목표 | 대회 날짜, 목표 기록, 현재 기록, 주간 거리, 가능 요일 |
| 주간 계획 | 해당 주, 요일별 훈련, 목표 거리·시간·강도 |
| 수행 기록 | 계획 ID, 완료 여부, 실제 거리·시간, 난이도, 미완료 이유 |
| 주간 피드백 | 해당 주, 수행 요약, 피드백과 다음 주 참고 사항 |

앱을 종료한 뒤에도 목표·계획·수행 기록·피드백을 다시 확인할 수 있도록 휴대폰에 저장한다. 개인 훈련 데이터는 GitHub에 올리지 않는다.

## 8. 개발 순서

1. 목표 설정과 주간 계획, 결과 입력, 피드백 화면을 구성한다.
2. Room을 연결해 입력 정보와 훈련 결과를 저장하고 복원한다.
3. 훈련 유형과 구성 기준을 확정하고 일주일 계획 생성 기능을 구현한다.
4. 수행 결과를 비교해 주간 요약과 피드백을 제공한다.
5. 다음 주 계획 반영과 전체 이용 흐름을 확인한다.

## 9. 완료 기준

- 목표·현재 상태·가능 요일을 반영한 일주일 계획을 표시한다.
- 결과 입력 후 계획과 실제 수행을 비교한 피드백을 제공한다.
- 가능하지 않은 요일, 입력 누락과 잘못된 수치를 검사한다.
- 미입력 기록을 훈련 실패로 단정하지 않는다.
- 다음 주 계획을 생성해도 이전 수행 기록을 유지한다.
- 앱 재실행 후 데이터를 복원하고 네트워크 없이 핵심 기능을 사용할 수 있다.

## 10. 초기 범위

첫 버전은 주간 훈련 계획, 간단한 수행 기록과 주간 피드백으로 한정한다. 지도, 코스 추천, GPS 자동 측정, 워치 연동, 회원가입, 서버 동기화, 소셜 기능과 복잡한 통계는 제외한다.
